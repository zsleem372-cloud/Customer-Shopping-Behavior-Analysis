# Customer Shopping Behavior Analysis

## 1. نبذة عن المشروع (Project Overview)

يهدف المشروع إلى تحليل سلوك التسوق لدى العملاء باستخدام Python وPandas وPower BI، بهدف فهم أنماط الشراء، وتحديد الفئات الأعلى مبيعًا، ومتابعة مؤشرات المبيعات والعملاء، واستخراج نتائج تساعد في اتخاذ قرارات أفضل.

## 2. وصف البيانات (Dataset Description)

- **اسم البيانات:** Shopping Trends Dataset
- **مصدر البيانات:** [Kaggle – Customer Shopping Trends Dataset](https://www.kaggle.com/datasets/iamsouravbanerjee/customer-shopping-trends-dataset)
- **عدد السجلات:** 3,900 سجل.
- **عدد الأعمدة:** 19 عمودًا.

تحتوي البيانات على معلومات عن العملاء والمنتجات والمشتريات وطرق الدفع والتقييمات وتفضيلات التسوق.

## 3. شرح أعمدة البيانات (Dataset Columns)

| اسم العمود | المعنى |
|---|---|
| Customer ID | رقم تعريف العميل |
| Age | عمر العميل |
| Gender | جنس العميل |
| Item Purchased | المنتج الذي تم شراؤه |
| Category | فئة المنتج |
| Purchase Amount (USD) | قيمة الشراء بالدولار |
| Location | موقع العميل |
| Size | مقاس المنتج |
| Color | لون المنتج |
| Season | الموسم |
| Review Rating | تقييم العميل |
| Subscription Status | حالة الاشتراك |
| Payment Method | طريقة الدفع المستخدمة |
| Shipping Type | نوع الشحن |
| Discount Applied | هل تم تطبيق خصم؟ |
| Promo Code Used | هل تم استخدام كود ترويجي؟ |
| Previous Purchases | عدد المشتريات السابقة |
| Preferred Payment Method | طريقة الدفع المفضلة |
| Frequency of Purchases | معدل تكرار الشراء |

## 4. الأدوات المستخدمة (Tools Used)

- **Python:** فحص البيانات وتجهيزها.
- **Pandas:** قراءة البيانات والتعامل معها.
- **Power BI:** إنشاء لوحة المعلومات وتحليل النتائج.
- **DAX:** إنشاء المقاييس الحسابية داخل Power BI.

## 5. فحص البيانات وتجهيزها (Data Cleaning & Preparation)

تم استخدام Python وPandas لفحص البيانات وتجهيزها للتحليل.

شملت خطوات العمل:
- فحص عدد السجلات والأعمدة.
- مراجعة أنواع البيانات.
- فحص القيم المفقودة.
- تجهيز البيانات للتصدير والاستخدام في Power BI.
- تصدير البيانات المجهزة في ملف CSV باسم `cleaned_Customer_Shopping.csv`.

أظهرت مراجعة البيانات النهائية عدم وجود قيم مفقودة.

## 6. أهم النتائج (Key Findings)

- **إجمالي العملاء:** 3,900.
- **متوسط قيمة الشراء:** 59.76 دولار.
- **إجمالي المبيعات:** حوالي 233 ألف دولار.
- **متوسط عمر العملاء:** 44.07 سنة.
- **متوسط تقييم العملاء:** 3.75 من 5.
- **أعلى فئة مبيعًا:** الملابس (Clothing)، بمبيعات بلغت حوالي 104 آلاف دولار.
- **توزيع العملاء حسب الجنس:** الذكور حوالي 68%، والإناث حوالي 32%.
- **أعلى موسم من حيث المبيعات:** الخريف (Fall)، بحوالي 60 ألف دولار.

## 7. لوحة المعلومات (Power BI Dashboard)

تم إنشاء لوحة معلومات تفاعلية باستخدام Power BI لعرض مؤشرات الأداء الرئيسية وتحليل سلوك العملاء.

تتضمن اللوحة:
- إجمالي العملاء.
- إجمالي المبيعات.
- متوسط قيمة الشراء.
- متوسط عمر العملاء.
- متوسط تقييم العملاء.
- المبيعات حسب فئة المنتج.
- توزيع العملاء حسب الجنس.
- المبيعات حسب طريقة الدفع.
- المبيعات حسب الموسم.
- أفضل 10 منتجات من حيث المبيعات.

## 8. التوصيات (Recommendations)

- التركيز على فئة الملابس للحفاظ على أدائها البيعي.
- دراسة الفروق في المبيعات بين الفئات والمنتجات.
- تحليل تقييمات العملاء لتحديد فرص تحسين تجربة التسوق.
- تطوير الحملات التسويقية بناءً على تفضيلات العملاء.
- متابعة المبيعات وسلوك العملاء باستخدام لوحة المعلومات.
- استخدام النتائج لدعم القرارات التسويقية والتجارية.

## 9. الخلاصة (Conclusion)

ساعد المشروع على تطبيق مهارات تحليل البيانات باستخدام Python وPandas وPower BI، بدايةً من فحص البيانات وتجهيزها، وصولًا إلى بناء لوحة معلومات تفاعلية واستخراج نتائج وتوصيات مبنية على البيانات.

يُظهر المشروع كيفية تحويل بيانات التسوق إلى مؤشرات واضحة يمكن الاستفادة منها في فهم سلوك العملاء ومتابعة أداء المبيعات.
