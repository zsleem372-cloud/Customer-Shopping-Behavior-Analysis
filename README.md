# تحليل سلوك التسوق لدى العملاء
Customer Shopping Behavior Analysis

## 1. نظرة عامة على المشروع
يهدف هذا المشروع إلى تحليل سلوك التسوق لدى العملاء باستخدام Python وPandas وPower BI، بهدف فهم أنماط الشراء، وتقييم أداء المبيعات، واستخراج رؤى تساعد في اتخاذ قرارات تجارية مبنية على البيانات.

يركز المشروع على الخصائص الديموغرافية للعملاء، وفئات المنتجات، والمبيعات الموسمية، وطرق الدفع، والاشتراكات، والخصومات، وتقييمات العملاء.

## 2. أهداف المشروع
- تحليل إجمالي المبيعات ومتوسط قيمة الشراء.
- تحديد فئات المنتجات والمواسم الأعلى مبيعًا.
- فهم توزيع العملاء وسلوكهم الشرائي.
- تحليل تكرار الشراء وحالة الاشتراك واستخدام الخصومات.
- مقارنة تقييمات العملاء بين فئات المنتجات المختلفة.
- تقديم توصيات عملية لتحسين الأداء ودعم اتخاذ القرارات.

## 3. الأدوات والتقنيات المستخدمة
- **Python:** معالجة البيانات وتجهيزها للتحليل.
- **Pandas:** تنظيف البيانات وتحليلها واستكشافها.
- **Power BI:** إنشاء لوحات المعلومات والتصورات البيانية.
- **DAX:** إنشاء المقاييس ومؤشرات الأداء الرئيسية.

## 4. وصف البيانات
تتكون مجموعة البيانات من 3,900 سجل و19 عمودًا، وتشمل معلومات عن العملاء وأعمارهم ونوعهم، والمنتجات المشتراة، وقيم المشتريات، وفئات المنتجات، والمواسم، وطرق الدفع، والخصومات، والاشتراكات، وتقييمات العملاء.

تم فحص البيانات للتحقق من القيم المفقودة والسجلات المكررة خلال مرحلة تجهيز البيانات.

## 5. مراحل تنفيذ المشروع

### أولًا: تنظيف البيانات وتجهيزها
- تحميل البيانات باستخدام Pandas.
- فحص بنية البيانات وأنواع الأعمدة.
- التحقق من القيم المفقودة والتكرارات.
- تجهيز البيانات لتكون مناسبة للتحليل والتصور البياني.

### ثانيًا: التحليل الاستكشافي للبيانات
تحليل المبيعات وسلوك العملاء، وتوزيع العملاء حسب النوع والعمر، وفئات المنتجات، والمبيعات الموسمية، وطرق الدفع، والاشتراكات، والخصومات، وتقييمات العملاء.

### ثالثًا: إنشاء لوحة المعلومات باستخدام Power BI

**الصفحة الأولى: Overview — نظرة عامة**
- إجمالي العملاء.
- إجمالي المبيعات.
- متوسط قيمة الشراء.
- متوسط أعمار العملاء.
- متوسط تقييمات العملاء.
- المبيعات حسب فئة المنتج.
- توزيع العملاء حسب النوع.
- المبيعات حسب طريقة الدفع.
- المبيعات حسب الموسم.
- أفضل 10 منتجات من حيث المبيعات.

**الصفحة الثانية: Customer Behavior Analysis — تحليل سلوك العملاء**
- تكرار الشراء.
- تحليل الاشتراكات.
- تحليل الخصومات.
- تقييمات العملاء حسب فئة المنتج.
- تحليل الفئات العمرية.
- تحليل أنواع الشحن.

**الصفحة الثالثة: Analysis & Recommendations — التحليل والتوصيات**
- عرض أهم النتائج المستخلصة من البيانات.
- تحديد فرص تحسين أداء المبيعات.
- تقديم توصيات لدعم القرارات التسويقية والتشغيلية.

## 6. أهم النتائج

- **إجمالي المبيعات:** حوالي 233 ألف دولار.
- **متوسط قيمة الشراء:** حوالي 59.76 دولار.
- **متوسط عمر العملاء:** حوالي 44.07 سنة.
- **متوسط تقييم العملاء:** حوالي 3.75 من 5.
- **أفضل فئة من حيث المبيعات:** الملابس، بحوالي 104 آلاف دولار.
- **أفضل موسم من حيث المبيعات:** الخريف، بحوالي 60 ألف دولار.
- **توزيع العملاء حسب النوع:** حوالي 68% ذكور و32% إناث.

### تحليل الاشتراكات
بلغ متوسط قيمة الشراء للعملاء غير المشتركين حوالي 59.87 دولار، مقابل 59.49 دولار للعملاء المشتركين، مما يشير إلى تقارب متوسط الإنفاق بين المجموعتين.

### تحليل تقييمات المنتجات
سجلت فئة الأحذية متوسط تقييم يقارب 3.79، بينما سجلت فئة الملابس متوسط تقييم يقارب 3.72.

## 7. التوصيات التجارية
- الاهتمام بفئات المنتجات الأعلى مبيعًا، مع متابعة هامش الربح.
- الاستفادة من أنماط المبيعات الموسمية في التخطيط للمخزون والحملات التسويقية.
- تطوير استراتيجيات تسويقية تناسب شرائح العملاء المختلفة.
- تحليل الفئات ذات التقييمات الأقل لتحديد فرص تحسين تجربة العملاء.
- تقييم فعالية الخصومات من خلال مقارنة المبيعات ومتوسط قيمة الشراء والربحية.
- تقييم الاشتراكات وبرامج الولاء باستخدام مؤشرات قابلة للقياس، مثل تكرار الشراء والاحتفاظ بالعملاء.

## 8. مخرجات المشروع
- ملف Python Notebook للتحليل وتجهيز البيانات.
- ملف البيانات بعد التنظيف.
- ملف لوحة المعلومات بصيغة Power BI.
- صور لوحة المعلومات والتوثيق الخاص بالمشروع.

## 9. الخلاصة
يوضح المشروع كيفية استخدام تحليل البيانات والتصور البياني لتحويل سجلات التسوق إلى رؤى مفيدة حول المبيعات وسلوك العملاء. ويساعد الجمع بين Python وPandas وPower BI في تحديد الأنماط الرئيسية وفرص التحسين، وتقديم توصيات تدعم اتخاذ قرارات تجارية مبنية على البيانات.
